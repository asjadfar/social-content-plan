# Caption Template — one post, two versions

> Write every caption twice: a Facebook version and an Instagram version.
> Same words, same offer, same hashtags — only the link line changes.
> Check both with `scripts/check_captions.py` before the approval gate.

## Rules for both versions

- English only. Short sentences, one idea per line.
- One emoji at most per paragraph.
- Knowledge posts end with a question — never drop it to save space.
- Hashtags at the end, 3–4 only. Never more than 5.
  - Standard: `#FragranceEmpire #PerfumeTips #PerfumeMalaysia #LuxuryPerfume`
  - Offer posts add: `#1111Sale #MegaSale` (or the current sale tag)
  - Reel posts add the product tag: `#DiorSauvage` / `#PacoRabanne` / `#Armani` (one only)
- Offer block (only when the brief has an offer) — identical wording on both platforms:
  `11.11 MEGA SALE — 50% OFF + FREE delivery across Malaysia, EXTRA 10% OFF with card payments. Sale ends 15 November.`
  (Replace with the current week's exact offer from the brief.)
- No price from memory — every price in a caption must be verified live that week (see SKILL.md Step 6).
- Never write "100% original" or any authenticity promise unless the owner explicitly approved it for this post.

## Facebook version

- Direct shop link in the caption: `https://fragranceempire.my`
  or the collection link for bundles: `https://fragranceempire.my/collections/bundles`
- Total length: **1,024 characters or fewer** (connector limit).

## Instagram version

- NO URLs anywhere in the caption. Replace the link line with: `Link in bio`
- Feed image must be the portrait 4:5 version (1080×1350); every video needs a matching cover image.

## Knowledge post — shape

```
[Hook line — the question the post answers] [emoji]
[2–4 short lines or bullet points with the answer]
[Question to the reader] 👇
[Offer block, only if the brief has an offer]
[Shop link (FB) / Link in bio (IG)]
[Hashtags]
```
